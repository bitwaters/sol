# Telegram 指令与回复

适用于授权管理员。发送 /help 或 /start 打开帮助页；也可使用 Telegram 命令菜单。帮助页提供查询快捷按钮，暂停、恢复和屏蔽通过对应指令操作。

## 帮助页

📖 指令帮助
仅授权管理员可使用。可点击下方查询按钮，或从 Telegram 命令菜单选择。

/help — 查看指令说明与快捷按钮
/start — 打开机器人使用指南
/status — 查看采集状态、信号和发送队列
/config — 查看当前策略阈值与采集设置
/stats — 查看信号表现与未推送原因
/wallets — 查看近30天观测到的关注钱包
/test — 检查机器人指令回复是否正常
/pause — 暂停新信号及跟进消息，保留退出提醒
/resume — 恢复新信号及跟进消息
/mute — 屏蔽代币：/mute 合约地址 [小时数]
/unmute — 解除屏蔽：/unmute 合约地址

屏蔽用法：/mute 合约地址 2（屏蔽2小时）；省略小时数则永久屏蔽。
解除屏蔽：/unmute 合约地址。将“合约地址”替换为实际 Solana 代币地址。
暂停后采集、评估、退出提醒及运维告警继续；恢复不会保证补发已过期信号。
消息按钮：打开 GMGN 查看代币；刷新提示等待下一轮评估；屏蔽该币会永久屏蔽新信号。
关注钱包页面仅展示本服务观测到的成交钱包，不代表完整关注名单。
所有时间均为 UTC。机器人只推送信息，不执行交易。

## 中文回复规则

- 运行状态：来源中文名称、UTC 时间、最近成功采集与最新已处理成交；队列区分待发送、发送中、可重试和重试耗尽。
- 配置：中文名称及美元、分钟、票数、百分比等单位；只显示策略配置，不显示凭证。
- 统计与每日报告：中文拦截原因，保留动态票数、保留率和价格倍数；未知原因归入待排查，原始原因仍保存在数据库。
- 钱包：近30天观测总数与最多50个展示数量分开，不视为完整关注列表。
- 测试：仅验证指令收发，不宣称完整信号链路通过。
- 信号与告警：来源、开发者持仓状态、安全指标和采集告警统一使用中文。
